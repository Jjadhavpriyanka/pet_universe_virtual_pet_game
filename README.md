# Pet Universe

## Overview
Pet Universe is a Java-based virtual pet simulation game that allows users to adopt, care for, and interact with virtual pets. Each pet possesses unique attributes and behaviours that change dynamically according to user interactions. The project demonstrates key OOP principles by crating a scalable and organised system for virtual pet management.

## Features
1. Adopt and manage virtual pets
2. Feed pets to maintain health and reduce hunger
3. Play with pets to increase happiness
4. Monitor pet attributes in real time
5. Dynamic pet behaviour based on player interactions
6. Object-oriented design using industry-standard principles
7. UML and object-oriented system modelling

## Technologies Used
1. Java
2. Object-Oriented Programming(OOP)
3. UML Modelling
4. Git
5. GitHub

## OOP Concepts Demonstrated
This project was designed to implement and demonstrates:

### Abstraction
Complex pet behaviours are simplified through well-defined classes and methods.

### Encapsulation
Pet attributes such as health, hunger, energy, and happiness are protected through private fields and controlled access methods.

### Inheritance
Different pet types inherit common characteristics from base classes while implementing specialised behaviours.

### Polymorphism
Pet actions can be performed differently depending on the pet type, allowing flexibility and extensibility.

## Pet Attributes
Each pet maintains several attributes:

No.  Attribute  Description
1.  Health  Overall wellbeing of the pet
2.  Hunger  Indicates when feeding is required
3.  Happiness  Represents pet satisfaction
4.  Energy  Determines activity capability

These attributes change based on user actions.
